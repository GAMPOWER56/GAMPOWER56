# Free-Space Cross-Polarization PhC Cavity Measurement System | ASDL (2026.03 ~ 진행 중)

> **한양대학교 ERICA ASDL(김영현 교수님 연구실) 학부연구생**
> **기간:** 2026.03 ~ 진행 중
> **주요 역할:** 광학계 설계·구성 부품 선정, 견적/발주 진행, 정렬 방식 설계

> ⚠️ 아직 구매/발주가 진행 중인 셋업으로, 정렬 결과나 실측 데이터는 없으며
> 광학계 설계 논리와 구성 요소, 진행 상황 위주로 정리했습니다.
> 완성되면 ASDL 자체 소자뿐 아니라 **MIT Englund Group 소자**도 이 셋업으로 함께 측정할 예정이라, 범용성을 고려해 설계하고 있습니다 (소자 관련 세부 내용은 비공개).

---

## 📌 Executive Summary

* **그레이팅 커플러/도파로 없이, 자유공간에서 캐비티를 측정하는 방식 설계**
  * 레이저 → 자유공간 → 대물렌즈로 시료에 수직 입사 → 반사·산란광을 같은 경로로 되돌려 검출하는 에피(epi) 반사형 구성
  * 입력·출력 편광판을 서로 90° 교차시켜, 직접 반사되는 배경광은 차단하고 캐비티에 의해 편광이 회전된 산란광만 선택적으로 검출하는 **cross-polarization** 방식 채택 (MIT의 PhC-SLM 측정 컨셉을 참고해 우리 플랫폼에 맞게 적용)
* **회전 없는 45° 편광 스킴**
  * 시료를 회전시키는 대신, 교차 상태를 유지한 입력·출력 편광판 쌍을 함께 45°/−45°로 세팅하는 방식으로 정렬 복잡도를 낮춤
* **부품 규격 통일 및 견적/발주 진행**
  * 전 광학 부품을 동일 포스트/마운트 규격(Ø1/2" 포스트, 광축 높이 4인치)으로 통일해 설계
  * 핵심 광학 부품(레이저·콜리메이터·빔스플리터·대물렌즈·파워미터)은 구매 완료, 마운트류는 견적 진행 중

## 🛠 측정계 구성 (설계 확정 부품)

| 구성 요소 | 스펙 | 역할 |
|------|------|------|
| 광원 | Santec TSL-210V (1500–1620nm 파장가변, GPIB 원격제어) | 측정 파장 스캔 |
| 아이솔레이터 | — | 역반사광 차단, 광원 보호 |
| 편광 컨트롤러 | — | 입력 편광 상태 조정 |
| 입력 콜리메이터 | Thorlabs C20APC-C (FC/APC, SM1) | 파이버 광 → 자유공간 평행광 변환 |
| 입력/출력 편광판 | LPNIR100-MP2 + RSP1/M 회전마운트 | −45°/+45° 교차 편광 세팅 (cross-pol 방식 핵심 부품) |
| 빔스플리터 | 50:50 비편광 큐브 (BSH1/M 마운트) | 입력광-시료 경로, 반사광-검출 경로 분리 |
| 대물렌즈 | **Olympus LCPLN50XIR, NA 0.65** | 시료 수직 입사·반사광 재커플링 |
| IR 정렬 조명/카메라 | 할로겐 광원 + Light Guide, 튜브렌즈(TTL200-S8) | 시료 정렬 및 실시간 모니터링 |
| 롱패스 필터 | FELH1450 | IR 조명 파장 차단, 신호 대역만 통과 |
| 검출기 | EXFO LTB-12 + FTBx-1750 모듈 (InGaAs, SCPI/GPIB/LAN) | 반사광 파워 측정 |

**광 경로:** 광원 → 아이솔레이터 → 편광 컨트롤러 → 입력 콜리메이터(자유공간 평행광) → 입력 편광판(−45°) → 빔스플리터 → 대물렌즈 → **시료(수직 입사)** → (반사·산란광, 역경로) → 빔스플리터 → 출력 편광판(+45°, 입력과 교차) → 롱패스 필터 → 출력 콜리메이터 → 검출기 · *(정렬 모니터링용으로 빔스플리터에서 IR 조명/카메라 경로 분기)*

> 광 경로 다이어그램은 실측 정렬 이전, 부품 배치를 설계하며 직접 스케치한 자료가 있어 Evidence에 추가 예정입니다.
