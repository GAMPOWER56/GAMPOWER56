## 📌 Executive Summary

* **그레이팅 커플러 없는 자유공간 측정을 전제로 한 캐비티 설계**
  * SiN-on-Si(SINS) 플랫폼에서, 도파로·그레이팅 커플러 없이 자유공간 수직입사·반사(cross-polarization resonant scattering)만으로 측정 가능한 W1 line-defect PhC 캐비티 설계
  * 선행연구(Debnath *et al.*, *Opt. Express*, 2017)의 완전 서스펜드 구조를 우리 플랫폼 제약(비서스펜드, 위쪽만 open, 아래 BOX 층 존재)에 맞게 재설계
* **FDTD + GME 하이브리드 계산 파이프라인 구축**
  * Lumerical 3D FDTD(정밀·고비용)와 legume 기반 Python GME(근사·고속)를 병행 사용해 파라미터 탐색 효율화
  * GME 방법론을 문헌값과 직접 대조해 신뢰성 사전 검증 후 실제 플랫폼 조건에 적용
* **크리티컬 커플링 관점의 설계 목표 재정의**
  * 링공진기의 κ/α(결합·손실) 개념을 PhC 캐비티에 적용 — in-plane 손실(미러 컬럼 수)과 vertical 손실(모드 형태)의 균형점을 목표로 설계 방향 설정
  * 단순 Q값 극대화가 아니라, 실측 가능한 크리티컬 커플링 지점 근처를 목표로 하는 실용적 설계 전환
* **시뮬레이션 스크립트 반복 디버깅 (v2 → v10, 9회 이상 개정)**
  * 대칭조건 오류, API 문법 오류, 신뢰 불가능한 스윕 결과의 원인 규명 등 체계적인 문제 해결 과정 진행

## 🛠 설계 환경 및 워크플로우

| 단계 | 도구 / 내용 |
|------|------|
| 밴드구조/모드 계산 (고속) | legume (Python Guided-Mode Expansion) — 단위격자 밴드구조 계산, 문헌값과 대조 검증 후 파라미터 스윕에 활용 |
| 3D 캐비티 시뮬레이션 (고정밀) | Lumerical FDTD — 공진 스펙트럼·Q값 계산, 벤더 제공 resonance-finder 로직 기반 피크 탐색 |
| 설계 목표 설정 | 단일포트 CMT 반사율 모델(R(Δ))로 크리티컬 커플링 조건 도출, Q_vertical/Q_in-plane 분리 측정 방식 설계 |
| 마스크 생성 | 확정 파라미터를 GDS 마스크 생성 스크립트에 반영 |
| 공정 전달 | 마스크 파일 외주 공정 발주 (8월 내 목표) |

**전체 흐름:** 선행연구 재현 검증(GME) → 실제 플랫폼 조건 파라미터 스윕 → 3D FDTD 정밀 검증 → 크리티컬 커플링 목표점 확정 → GDS 마스크 생성 → 외주 공정 발주 → (→ [광학 측정계](../setup)에서 측정)

## ✅ 결론

선행연구(Debnath *et al.*, 2017)를 그대로 적용할 수 없어, 우리 플랫폼 조건(비서스펜드, 위쪽만 open)에 맞게 다시 설계하는 과정을 진행했습니다. 시뮬레이션 스크립트가 신뢰할 수 없는 결과를 낼 때마다 v2부터 v10까지 버전을 나눠가며 원인을 하나씩 격리·수정했고, 특히 짧은 시뮬레이션 시간으로 인한 대규모 스윕 결과 오염처럼 겉으로는 "그럴듯해 보이지만 실제로는 신뢰할 수 없는" 결과를 정량적으로 검증해 걸러내는 과정을 거쳤습니다. 아직 크리티컬 커플링 목표점을 확정하지 못했고, 이 값이 정해져야 마스크 설계 단계로 넘어갈 수 있는 상태입니다.
